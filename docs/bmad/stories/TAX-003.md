### Spec discrepancy found and fixed

SPEC-TAX-006 S-DB-009 expected SQLSTATE 22003 for 5-decimal-place taxable_base.
Actual PostgreSQL NUMERIC(19,4) behaviour: silently rounds extra fractional digits.
Scale enforcement is at the application layer (domain: TaxComponent.taxableBase scale ≤ 4).
Test updated to verify rounding (not rejection) for extra decimals, and 22003 for integer-part overflow.
