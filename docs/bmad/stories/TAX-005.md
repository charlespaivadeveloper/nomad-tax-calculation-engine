### Spec discrepancy found (S-DE-005)

SPEC-TAX-003 §9 S-DE-005 states `10.0000 × 0.055000000 = 0.5500000000000 → 0.56`.
Actual: 0.5500000000000 at scale 2 = **0.55** (exact, no half-case; dropped part = 0, not 0.005).
Fixed: S-DE-005 uses `rate = 0.055500000` → intermediate 0.555 → HALF_EVEN → 0.56 (last digit 5 is odd).
S-DE-005b added for round-down case: `3.0000 × 0.075000000 = 0.225` → 0.22 (last digit 2 is even). Both spec cases exercised correctly.
