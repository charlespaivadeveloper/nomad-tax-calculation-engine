---

## 1. Purpose

Define the complete HTTP REST contract for the tax calculation engine: wire formats (request bodies, response bodies, headers, status codes), error shape, decimal serialisation policy, and observability headers. This spec is the normative source for the interface-adapters layer (`tax-interface-adapters`). Domain logic is not defined here — it is referenced from SPEC-TAX-001 through SPEC-TAX-003 and SPEC-TAX-005.

Three endpoints are in scope for MVP:

| Endpoint | Method | Purpose |
|---|---|---|
| `/v1/tax-calculations` | POST | Submit a new synthetic tax calculation |
| `/v1/tax-calculations/{id}` | GET | Retrieve a previously persisted calculation by UUID |
| `/v1/tax-calculations/{id}/replays` | POST | Re-execute the original calculation and compare to stored result |

---

## 2. API endpoints overview

All paths are prefixed `/v1` (RF-007 / RNF-007). No path versioning via query string or header is used in MVP.

| Method | Path | Auth | Idempotency-Key | Description |
|---|---|---|---|---|
| POST | `/v1/tax-calculations` | Bearer JWT | Required | Calculate; persists result atomically |
| GET | `/v1/tax-calculations/{id}` | Bearer JWT | — | Retrieve stored result |
| POST | `/v1/tax-calculations/{id}/replays` | Bearer JWT | — | Replay calculation; compare to stored |

---

## 3. Authentication and tenant propagation

Every request must carry a Bearer JWT in the `Authorization` header. The server extracts `tenant_id` from the JWT `tenant_id` claim; this value is used as `TaxOperationInput.tenantId` and enforces tenant isolation. The request body must **not** contain a `tenantId` field — any such field must be rejected with 400.

| JWT claim | Required | Usage |
|---|---|---|
| `tenant_id` | Yes | Populates `TaxOperationInput.tenantId`; filters all DB queries |
| Standard `exp`, `iat`, `sub` | Yes | Standard JWT validation |
| Scopes / roles | To be defined (OQ-RC-001) | Authorisation for write vs. read |

Absent or invalid JWT → 401. Valid JWT, `tenant_id` claim missing → 403 `TENANT_NOT_FOUND`.

## 4. Request wire format

### 4.1 POST `/v1/tax-calculations`

**Required header:**

| Header | Type | Constraint |
|---|---|---|
| `Authorization` | `Bearer <jwt>` | Required; standard JWT |
| `Idempotency-Key` | string | Required; 1–128 characters; opaque client string |
| `X-Correlation-ID` | UUID string | Optional; echoed in response; generated by server if absent |
| `Content-Type` | `application/json` | Required |

**Request body** (`CalculationRequest`):

```json
{
  "operationId":        "OP-2026-001",
  "operationDate":      "2026-01-15",
  "currency":           "BRL",
  "classificationCode": "GOODS_GENERAL",
  "taxableBase":        "1000.00",
  "simulationContext":  "SYNTHETIC"
}
```

| Field | JSON type | Constraint | Maps to domain |
|---|---|---|---|
| `operationId` | string | non-blank; 1–255 chars | `OperationId.value` |
| `operationDate` | string | ISO-8601 date (`yyyy-MM-dd`); `<= today` | `TaxOperationInput.operationDate` |
| `currency` | string | enum: `["BRL"]` | `Currency.BRL` |
| `classificationCode` | string | 1–64 chars; pattern `^[A-Z0-9_]+$` | `ClassificationCode.value` |
| `taxableBase` | string | pattern `^(0|[1-9][0-9]*)(\.[0-9]{1,4})?$`; parsed as `BigDecimal`; `> 0.00`; max scale 4 | `TaxOperationInput.taxableBase` |
| `simulationContext` | string | enum: `["SYNTHETIC"]` | `SimulationContext.SYNTHETIC` |

`additionalProperties: false` — any unrecognised field causes 400.

The mapper in `tax-interface-adapters` constructs `TaxOperationInput` from this body, injecting `tenantId` from the JWT and `idempotencyKey` from the header. Any mapping failure before domain validation causes 400 `VALIDATION_ERROR`.

### 4.2 GET `/v1/tax-calculations/{id}`

**Path parameter:**

| Parameter | In | Type | Constraint |
|---|---|---|---|
| `id` | path | string | UUID format; non-null |

No request body. `Accept: application/json` preferred.

### 4.3 POST `/v1/tax-calculations/{id}/replays`

**Path parameter:**

| Parameter | In | Type | Constraint |
|---|---|---|---|
| `id` | path | string | UUID format; references an existing `calculationId` |

No request body. The replay uses the stored canonical input snapshot (see SPEC-TAX-007 §3) to re-execute the full pipeline and compare components and total. No overrides are accepted in MVP (OQ-RC-004).

## 5. Response wire formats

### 5.1 `CalculationResponse`

Returned by POST (201 on new calculation, 200 on idempotent replay) and GET (200).

```json
{
  "calculationId":      "123e4567-e89b-12d3-a456-426614174000",
  "status":             "CALCULATED",
  "currency":           "BRL",
  "components": [
    {
      "taxType":     "CBS",
      "taxableBase": "1000.0000",
      "rate":        "0.088000000",
      "amount":      "88.00"
    },
    {
      "taxType":     "IBS",
      "taxableBase": "1000.0000",
      "rate":        "0.177000000",
      "amount":      "177.00"
    }
  ],
  "totalTax":           "265.00",
  "ruleVersionId":      "aabbccdd-…",
  "engineVersion":      "1.0.0",
  "simulationContext":  "SYNTHETIC",
  "inputCanonicalHash": "a3f9…64hexchars…b2e1"
}
```

| Field | JSON type | Source | Notes |
|---|---|---|---|
| `calculationId` | string (UUID) | `CalculationResult.calculationId` | Stable; used as path `{id}` |
| `status` | string | `CalculationResult.status` | Always `"CALCULATED"` in MVP |
| `currency` | string | `CalculationResult.currency` | Always `"BRL"` in MVP |
| `components` | array | `CalculationResult.components` | Non-empty; ordered CBS before IBS |
| `totalTax` | string | `CalculationResult.totalTax.amount` | Decimal string, scale 2 |
| `ruleVersionId` | string (UUID) | `CalculationResult.ruleVersionId` | References `TaxRuleSnapshot.id` |
| `engineVersion` | string | `CalculationResult.engineVersion` | Semantic version string |
| `simulationContext` | string | `CalculationResult.simulationContext` | Always `"SYNTHETIC"` |
| `inputCanonicalHash` | string | `CalculationResult.inputCanonicalHash` | 64-char lowercase hex (SPEC-TAX-001 §4) |

`additionalProperties: false`.

### 5.2 `TaxComponent` wire form

Each element of `components`:

| Field | JSON type | Source | Format |
|---|---|---|---|
| `taxType` | string | `TaxComponent.taxType` | `"CBS"` or `"IBS"` |
| `taxableBase` | string | `TaxComponent.taxableBase` | Decimal string, scale 4 (`toPlainString()`) |
| `rate` | string | `TaxComponent.rate` | Decimal string, scale 9 (`toPlainString()`) |
| `amount` | string | `TaxComponent.amount.amount` | Decimal string, scale 2 (`toPlainString()`) |

All four numeric fields are serialised as JSON **strings**, never as JSON `number`. See §8.

### 5.3 `ReplayResponse`

Returned by POST `/v1/tax-calculations/{id}/replays` (200).

```json
{
  "calculationId":        "123e4567-…",
  "matchesOriginal":      false,
  "originalEngineVersion": "1.0.0",
  "replayEngineVersion":   "1.1.0",
  "divergences": [
    {
      "field":    "components[0].amount",
      "original": "88.00",
      "replay":   "88.01"
    }
  ]
}
```

| Field | JSON type | Present when | Notes |
|---|---|---|---|
| `calculationId` | string (UUID) | Always | Echoes path `{id}` |
| `matchesOriginal` | boolean | Always | `true` iff replay produces identical components and totalTax |
| `originalEngineVersion` | string | Always | From stored `CalculationResult.engineVersion` |
| `replayEngineVersion` | string | Always | Current engine version used in replay |
| `divergences` | array | Always | Empty array when `matchesOriginal = true`; non-empty when `false` |

Each `divergences` element:

| Field | JSON type | Notes |
|---|---|---|
| `field` | string | JSON path to diverging field (e.g., `"components[1].amount"`, `"totalTax"`) |
| `original` | string | Stored value at that field (always a string) |
| `replay` | string | Recomputed value at that field |

Domain logic for replay is specified in SPEC-TAX-008.

### 5.4 Problem Details (RFC 9457)

All error responses use `Content-Type: application/problem+json` and this schema:

```json
{
  "type":          "https://errors.nomad-tax.example/RULE_NOT_FOUND",
  "title":         "Rule Not Found",
  "status":        422,
  "detail":        "no published rule for GOODS_GENERAL [CBS] on 2026-01-15",
  "code":          "RULE_NOT_FOUND",
  "correlationId": "uuid-string"
}
```

| Field | Required | Notes |
|---|---|---|
| `type` | Yes | URI uniquely identifying the error class; never an interactive URL |
| `title` | Yes | Short human-readable summary; stable per `code` |
| `status` | Yes | Mirrors the HTTP status integer |
| `detail` | Yes | Context-specific message; must not contain PII, tenant internals, or stack traces |
| `code` | Yes | Machine-readable error code (see §6 error code table) |
| `correlationId` | Yes | UUID; echoes `X-Correlation-ID` header or server-generated value |

## 6. HTTP status code matrix

| Scenario | HTTP Status | `code` | `Content-Type` |
|---|---|---|---|
| New calculation persisted | 201 Created | — | `application/json` |
| Idempotent retry (committed) | 200 OK | — | `application/json` |
| GET/replay success | 200 OK | — | `application/json` |
| Missing required field or header | 400 Bad Request | `VALIDATION_ERROR` | `application/problem+json` |
| Invalid field format | 400 Bad Request | `VALIDATION_ERROR` | `application/problem+json` |
| No Bearer token | 401 Unauthorized | `UNAUTHENTICATED` | `application/problem+json` |
| JWT missing `tenant_id` claim | 403 Forbidden | `TENANT_NOT_FOUND` | `application/problem+json` |
| Calculation not found (own tenant) | 404 Not Found | `CALCULATION_NOT_FOUND` | `application/problem+json` |
| Calculation not found (cross-tenant, non-disclosing) | 404 Not Found | `CALCULATION_NOT_FOUND` | `application/problem+json` |
| Duplicate Idempotency-Key with different body | 409 Conflict | `IDEMPOTENCY_CONFLICT` | `application/problem+json` |
| Multiple PUBLISHED rules match | 409 Conflict | `RULE_AMBIGUOUS` | `application/problem+json` |
| No PUBLISHED rule found | 422 Unprocessable Entity | `RULE_NOT_FOUND` | `application/problem+json` |
| In-progress concurrent duplicate | 503 Service Unavailable | `DEPENDENCY_UNAVAILABLE` | `application/problem+json` |
| Persistence store unavailable | 503 Service Unavailable | `DEPENDENCY_UNAVAILABLE` | `application/problem+json` |

The 404 response for a cross-tenant resource must be **identical** to a not-found response — no field may distinguish the two cases (non-disclosing tenant isolation).

## 7. Header contracts

### Request headers

| Header | Endpoints | Required | Constraint |
|---|---|---|---|
| `Authorization` | All | Yes | `Bearer <jwt>`; standard JWT |
| `Idempotency-Key` | POST `/v1/tax-calculations` | Yes | 1–128 chars; opaque string |
| `X-Correlation-ID` | All | No | UUID string; echoed in response |
| `Content-Type` | POST endpoints | Yes | `application/json` |
| `Accept` | All | No | Defaults to `application/json` |

### Response headers

| Header | Endpoints | Present | Notes |
|---|---|---|---|
| `Content-Type` | All | Always | `application/json` (2xx) or `application/problem+json` (errors) |
| `X-Correlation-ID` | All | Always | Echoes request value or server-generated UUID |
| `Retry-After` | POST `/v1/tax-calculations` (503 in-progress) | Conditional | Value: `2` (seconds); required when `code = DEPENDENCY_UNAVAILABLE` from an in-progress concurrent duplicate |
| `Location` | POST `/v1/tax-calculations` (201) | Yes | `/v1/tax-calculations/{calculationId}` |

## 8. Decimal serialisation policy

All monetary and rate values in request and response bodies are JSON **strings**, never JSON `number`. This prevents precision loss during JSON parsing by clients using IEEE 754 floating-point.

| Value | Wire format | Example |
|---|---|---|
| `taxableBase` (request) | String decimal, 1–4 decimal places | `"1000.00"` |
| `taxableBase` (response, per component) | String decimal, exactly 4 decimal places (`toPlainString()`) | `"1000.0000"` |
| `rate` | String decimal, exactly 9 decimal places (`toPlainString()`) | `"0.088000000"` |
| `amount` (per component) | String decimal, exactly 2 decimal places | `"88.00"` |
| `totalTax` | String decimal, exactly 2 decimal places | `"265.00"` |

No scientific notation. No locale-specific separators. The serialiser must call `toPlainString()` on `BigDecimal`, never `toString()`.

## 9. Invariants

| ID | Invariant |
|---|---|
| INV-RC-001 | Every response body field for monetary values is a JSON string; a JSON number for any monetary field is a contract violation |
| INV-RC-002 | `simulationContext` is always `"SYNTHETIC"` in every response; any other value is a contract violation |
| INV-RC-003 | `tenantId` is never serialised in any response body (GET, POST 2xx, replay, or error) |
| INV-RC-004 | A 404 response for a cross-tenant resource is byte-for-byte indistinguishable from a genuine not-found 404 |
| INV-RC-005 | `X-Correlation-ID` is present in every response, populated from the request header or server-generated |
| INV-RC-006 | Error responses always use `Content-Type: application/problem+json`; 2xx responses always use `Content-Type: application/json` |
| INV-RC-007 | `components` in `CalculationResponse` is never empty and always ordered CBS before IBS |
| INV-RC-008 | POST `/v1/tax-calculations` returns 201 for a new calculation and 200 for an idempotent replay; clients must treat 200 from a POST as a cache hit |
| INV-RC-009 | No stack trace, tenant identifier, DB row ID, or internal host name may appear in any error `detail` field |
| INV-RC-010 | The `Location` header on 201 always points to the resource retrievable by GET `/v1/tax-calculations/{calculationId}` |

## 10. Failure modes (HTTP layer)

| Trigger | Interactor result | HTTP Status | Code |
|---|---|---|---|
| `Idempotency-Key` header absent | — (pre-domain check) | 400 | `VALIDATION_ERROR` |
| `Idempotency-Key` length > 128 | — (pre-domain check) | 400 | `VALIDATION_ERROR` |
| Required body field absent | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `classificationCode` pattern mismatch | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `taxableBase` not parseable | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `taxableBase` scale > 4 | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `taxableBase <= 0` | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `operationDate` in future | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `currency != BRL` | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| `simulationContext != SYNTHETIC` | `DomainError(VALIDATION_ERROR)` | 400 | `VALIDATION_ERROR` |
| Absent/invalid JWT | — (filter/security layer) | 401 | `UNAUTHENTICATED` |
| JWT `tenant_id` claim absent | `DomainError(TENANT_NOT_FOUND)` | 403 | `TENANT_NOT_FOUND` |
| Calculation not found (own or cross-tenant) | `DomainError(CALCULATION_NOT_FOUND)` | 404 | `CALCULATION_NOT_FOUND` |
| Same Idempotency-Key, different body | `DomainError(IDEMPOTENCY_CONFLICT)` | 409 | `IDEMPOTENCY_CONFLICT` |
| Multiple PUBLISHED rules match | `DomainError(RULE_AMBIGUOUS)` | 409 | `RULE_AMBIGUOUS` |
| No PUBLISHED rule matches | `DomainError(RULE_NOT_FOUND)` | 422 | `RULE_NOT_FOUND` |
| In-progress concurrent duplicate | `DomainError(DEPENDENCY_UNAVAILABLE)` | 503 + `Retry-After: 2` | `DEPENDENCY_UNAVAILABLE` |
| Persistence unavailable | `DomainError(DEPENDENCY_UNAVAILABLE)` | 503 | `DEPENDENCY_UNAVAILABLE` |

## 13. Architecture constraints

| Constraint | Detail |
|---|---|
| HTTP controllers | Module `tax-interface-adapters`; package `tax.adapters.web` |
| Request/response mappers | Module `tax-interface-adapters`; must not use domain types as Jackson-annotated POJOs |
| Spring annotations | Allowed only in `tax-interface-adapters` and `tax-frameworks`; forbidden in `tax-domain` and `tax-usecases` |
| `tenantId` injection | Must come from JWT claim inside `tax-interface-adapters`; never from request body |
| RFC 9457 serialisation | `application/problem+json` media type must be set explicitly; must not fall through to Spring's default error format |
| Decimal serialisation | Serialiser must call `BigDecimal.toPlainString()`; `ObjectMapper` must not register `NumberModule` or `StdDeserializer<Number>` for domain numeric fields |
| ArchUnit rule | `noClasses().that().resideInAPackage("tax.adapters.web..").should().dependOnClassesThat().resideInAPackage("tax.frameworks..")` |
| OpenAPI artifact | `specs/openapi/tax-calculation-v1.yaml` is the normative machine-readable contract; it must stay in sync with this spec; divergence is a G2/G3 defect |
